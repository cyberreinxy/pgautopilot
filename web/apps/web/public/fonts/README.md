# Self-hosted fonts

Place the woff2 files below in this folder. They are referenced by the
`@font-face` rules in `apps/web/src/styles/globals.css`.

`font-display: swap` is already set, so text renders immediately with the
fallback stack until the files load.

## AlanSans (UI / main font)

- `AlanSans-Regular.woff2` (400)
- `AlanSans-Medium.woff2` (500)
- `AlanSans-SemiBold.woff2` (600)
- `AlanSans-Bold.woff2` (700)

## JetBrains Mono (code)

- `JetBrainsMono-Regular.woff2` (400)
- `JetBrainsMono-Medium.woff2` (500)
- `JetBrainsMono-SemiBold.woff2` (600)
